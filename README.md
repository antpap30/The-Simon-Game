# 🎮 Simon Game

A digital, interactive version of the classic 1970s memory game **Simon**, built using frontend web technologies. Test your memory and see how long of a color sequence you can follow!

## ✨ Features
- **Dynamic Sequence Generation:** The game generates a random sequence of colors and sounds that grows longer with each successful level.
- **Interactive Gameplay:** Click-based player input with visual button feedback (animations) and distinct audio tones for each color.
- **Keyboard Support:** Press the 'A' key to start the game.
- **Game Over & Restart Logic:** Detects incorrect user input and resets the game state.

## 🛠️ Technologies Used
- **HTML5 / CSS3:** Structure and styling of the game board and buttons.
- **JavaScript (ES6):** Core game logic, state management, and arrays.
- **jQuery:** DOM manipulation, event listeners, and animations (`fadeIn`, `fadeOut`, `addClass`).
- **Web Audio API:** Dynamic sound generation for each button press.

## 🚀 How to Play
1. Open the live version or clone the repository.
2. Press the **'A'** key on your keyboard to start the game.
3. Watch the flashing color sequence and repeat it by clicking the corresponding buttons in the exact same order.
4. Each successful round advances you to the next level!
